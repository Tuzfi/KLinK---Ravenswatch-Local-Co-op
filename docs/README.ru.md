# KlinK - Сетевой мод для Ravenswatch

Мод для совместной онлайн-игры в **Ravenswatch** (через Radmin VPN, ZeroTier или локальную сеть) без зависимости от внешних серверов.

- **Версия игры:** `1.06.00.04.27511` (`Build 2026/09/07 #16d45d2f01`)

## Важно

Этот репозиторий **не** распространяет игру и какие-либо её копии. Для игры у вас уже должен быть установлен **Ravenswatch** — KlinK нужен только для того, чтобы играть по сети без внешних серверов.

## Установка

1. Скопируйте всё содержимое папки `kit/` (`KlinK.bat`, `winhttp.dll` и `mods/`) в папку с `Ravenswatch.exe`.
2. Подключитесь с друзьями к одной сети Radmin VPN (или локальной сети).

## Как использовать

Запустите **`KlinK.bat`** (при первом запуске попросит ввести имя в игре):

- **Хост (создаёт лобби):** выберите `2`, подтвердите ваш IP из Radmin и дождитесь запуска игры. Передайте друзьям IP с точками из окна консоли (например, `26.10.10.2`), а затем код лобби из игры. Не закрывайте свёрнутое окно сервера во время игры.
- **Клиент (подключается):** выберите `1`, введите IP хоста с точками (например, `26.10.10.2`) и после запуска игры зайдите по коду лобби.
- **Сменить имя:** выберите `3` в меню `KlinK.bat`.

## Примечания

- При первом запуске Брандмауэр Windows открывает только порты мода (`TCP 8090` и `UDP 30100`) с ограничением на подсети LAN/VPN. Используйте только в локальной сети или приватном VPN со знакомыми (не пробрасывайте порты напрямую в интернет).
- Все файлы, настройки, профиль и `_log.txt` находятся внутри `mods/KlinK/`.
